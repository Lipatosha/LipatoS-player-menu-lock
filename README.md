# LipatoS - Ограничение меню особенностей, заклинаний и эффектов

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который ограничивает контекстные меню для обычных игроков.

Во вкладках **«Особенности»** и **«Заклинания»** скрываются запрещённые действия с предметами, а для пассивных эффектов скрывается удаление. Пункт **«Использовать»** модуль не изменяет.

## Версия

**1.3.1**

## Совместимость

- Foundry VTT: **14.367**
- D&D 5e: **6.0.0–6.0.3**

## Возможности

- скрывает у игроков пункт **«Передать предмет»**;
- скрывает создание свитка;
- скрывает удаление особенностей и заклинаний;
- скрывает удаление пассивных эффектов;
- не вмешивается в пункт **«Использовать»**;
- фильтрует как стандартные пункты меню D&D 5e, так и поздно добавленные пункты;
- для ГМ и Assistant GM интерфейс остаётся без изменений.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-player-menu-lock/main/module.json`
